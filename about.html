判定标准与提交规则

这份页面的唯一作用：让两个人标同一篇论文，得出同一个分。标之前请先读完。

三条纪律

  1. 只记录「有没有给」，不评价好坏、不评价作者水平。 全站不出现「差」「不合格」「灌水」这类词。
  2. 只看这一篇。 不去查作者的其他论文，不假设「他没写但应该懂」。
  3. 目标是判断「能不能照着做」，不是读懂论文。 每篇约 10 分钟，超时说明你在读内容，而不是在标注。
判定依据只有一个：论文里白纸黑字写了没有。写了但放在附录里，算写了；只在图里隐约可见、读不出数值，算「部分给出」。

四档评分

分值含义
2明确给出，照它就能做
1给了但不完整，需要猜
0未给出
NA该类论文不该有此项（例如纯算法文章没有仿真设置）

六项怎么判

1. 对象模型 m1_model

问句：有没有被控对象的数学描述，且参数是具体数值？

分特征
2给出传递函数/状态方程/差分方程，符号有数值且带单位；或给出参数表（K、T、τ 等逐项有值）
1有模型形式，但参数写「由实验辨识得到」而未给值；或只给部分参数；或只在 Simulink 截图里出现数值
0只有「液压系统」「伺服机构」之类文字描述；或写「模型见文献[12]」
正例（判 2）：阀控缸的传递函数为 G(s)=K/(s(T₁s+1)(T₂s+1))，其中 K=0.032 m³/(s·A)，T₁=0.12 s，T₂=0.008 s。
反例（判 1）：压力机液压系统可用二阶模型描述，其参数通过实验辨识获得。

易错：有框图 ≠ 有模型（框图属于控制器结构）；参数只给范围且未指定仿真取值 → 1。

2. 建模过程 m2_deriv

问句：有没有从机理到模型的推导，能看到中间步骤？

分特征
2至少两步推导，中间式可见（如 流量方程 → 力平衡 → 拉氏变换）
1只给起止两步、中间跳过；或「由机理可得」配一个引用
0直接抛出传递函数，无任何来源

易错：不要因为「这篇重点是控制、建模可以省略」就提分，按事实判。推导在附录里算 2。

3. 控制器结构 m3_struct

问句：有没有控制律的数学表达式或控制框图？

分特征
2写出 PID 三项表达式、自适应律，或优化问题的完整形式（目标函数 + 约束 + 待优化变量）
1只有文字「采用 PID 控制」；或有框图但无一行公式
0完全没交代控制结构

优化类特别注意：只写「用 PSO 优化 PID 参数」但没给目标函数（ITAE？ISE？带超调惩罚？），记 1——目标函数不明确，结果无法复现。

4. 控制器参数 m4_params

问句：有没有能直接抄进代码的参数？

分特征
2Kp/Ti/Td 有数值；优化类：算法超参数（种群数、迭代数、权重、搜索区间）＋最终最优参数都给全
1只给一部分：给了 Kp 没给 Ti/Td；或只给超参数没给最终参数
0完全没有

高频陷阱：论文说「整定后的参数见表 3」，翻到表 3 只有超调量和调节时间，没有 Kp/Ti/Td —— 判 0，不是 1，因为参数根本没出现。

5. 仿真设置 m5_simset

数四项里给了几项：① 采样步长或求解器；② 仿真时长；③ 初值/初始状态；④ 输入幅值或扰动位置。

分特征
2≥3 项
11~2 项（只写「在 MATLAB/Simulink 中仿真」不算任何一项）
00 项

6. 响应曲线 m6_plot

问句：有没有一张图，能让你读出超调量和调节时间？

分特征
2时域响应曲线（阶跃/跟踪/扰动），坐标轴有标签和单位，至少能读出超调、调节时间、稳态误差中的两项
1有曲线但读不出：无坐标数值、截图模糊、只给局部放大、或只有柱状对比图
0没有任何响应图，只有数字表格

易错：Bode 图/根轨迹不能替代阶跃响应，只有频域图 → 1。

总评 repro 怎么给

  1. 硬门槛：对象模型或控制器参数为 0 → 直接判「不能」。
  2. 否则数缺失项（六项里记 0 或 1 的个数，NA 不计）：
    • 缺 0~1 项，且缺的是可合理推断的（如未写初值但零初始显然）→ 能
    • 缺 2~3 项 → 存疑
    • 缺 ≥4 项 → 不能
  3. 在备注里写一句缺什么，例如：缺：m5(初值)、m6(无响应图)。

论文类型先判

仿真 只有软件结果；实验 有实验台或样机数据；工程 是现场应用。类型必须在标六项之前定，因为标准不同——纯仿真论文不该苛求实测数据。

怎么提交

  1. 点右上角「提交一篇标注」，按表单填写（一个 Issue 只放一篇论文）。
  2. 表单里的字段与本站六项一一对应，请先按上面的判定标准自己判一遍。
  3. 提交后不用再管数据文件：维护者给 Issue 打上 已收录 标签（或仓库主人自己提交时直接），系统会把这一条写进数据并重新生成页面，约 1 分钟后刷新即可看到。
  4. 发现已有条目判错，同一入口提「纠错」，标题写 [纠错] 编号。

提交流程不涉及上传文件，也不会修改你的账号；Issue 里只会出现你填写的内容。

数据与版权

本站只保存书目信息（标题、期刊、年份、DOI）与标注结果，不存储、不转载论文全文或图片。想读原文请按 DOI 自行到知网等数据库获取。标注仅记录「论文中是否给出某项」这一客观事实，不构成对论文质量的评价。

关于统计口径

  • 未给全率的计算分母不含 NA，按论文类型分组看更有意义。
  • 「未给出（0）」和「给得不全（1）」分开统计——这是两个不同的问题，合并会失真。
  • 最有用的一个数字：六项里哪一项缺失最多，那就是复现卡点的排序。
